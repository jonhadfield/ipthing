Get your public IP with curl

From a terminal, ipthing.net returns JSON: your public IP, approximate location, the headers you sent, and TLS details. Browsers (and clients that explicitly prefer text/html) still get HTML on the same URL.

How do I get my public IP with curl?

curl https://ipthing.net

Non-browser clients receive JSON. Print only the address:

curl -s https://ipthing.net | jq -r .IPAddr

Field names are PascalCase and match the labels on the HTML page. IPAddr is the TCP or QUIC peer — not X-Forwarded-For.

How do I check IPv4 or IPv6 with curl?

curl -4 https://ipthing.net
curl -6 https://ipthing.net

Without -4 or -6, curl uses whichever address family DNS prefers. IPThing accepts both. More detail: IPv6 address check.

Why does curl get JSON instead of HTML?

A browser User-Agent (Mozilla, AppleWebKit, Gecko, …) receives HTML, as does a non-browser client with Accept: text/html preferred over JSON. Typical curl sends Accept: */* and gets pretty-printed JSON.

HTTP without TLS

curl http://ipthing.net

Plain HTTP stays available on purpose, for scripts and images that have no CA bundle. There is no redirect to HTTPS.
