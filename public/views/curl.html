Get your public IP with curl

From a terminal, ipthing.net returns JSON: your public IP, approximate location, the headers you sent, and TLS details. Browsers still get HTML on the same URL.

curl https://ipthing.net

IPv4 and IPv6

curl -4 https://ipthing.net
curl -6 https://ipthing.net

Without -4 or -6, curl uses whichever address family DNS prefers. IPThing accepts both.

HTTP without TLS

curl http://ipthing.net

Plain HTTP stays available on purpose, for scripts and images that have no CA bundle. There is no redirect to HTTPS.

Print only the address

curl -s https://ipthing.net | jq -r .IPAddr

Field names are PascalCase and match the labels on the HTML page. IPAddr is the TCP or QUIC peer — not X-Forwarded-For.

Example JSON

{
  "IPAddr": "203.0.113.50",
  "IPFamily": "ipv4",
  "Country": "US",
  "Org": "AS65536 Example ISP",
  "UserAgent": "curl/8.0.0",
  "Proto": "HTTP/2.0",
  "TLSVersion": "TLS 1.3",
  "JA4": "t13d…",
  "XFF": ""
}

A browser User-Agent (Mozilla, AppleWebKit, Gecko, …) receives HTML instead. Request headers and TLS / JA3 / JA4 are documented separately. See live traffic mix at stats.ipthing.net.
