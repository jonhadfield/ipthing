What is my IPv6 address?

Open ipthing.net for the address this server saw on your connection. The IP Family row is ipv6 or ipv4. That value is the TCP or QUIC peer — not a forwarding header.

IPv6 vs IPv4 on one URL

IPThing listens on both address families. Browsers and most clients pick one path via DNS. Dual-stack devices often prefer IPv6 when a AAAA record works, so you may see a long hexadecimal address even if you also have IPv4.

Force a family with curl

curl -6 https://ipthing.net
curl -4 https://ipthing.net

-6 uses IPv6 only; -4 uses IPv4 only. Print just the address:

curl -6 -s https://ipthing.net | jq -r .IPAddr

More curl examples: curl JSON.

What an IPv6 address looks like

Public IPv6 addresses are 128-bit values written as eight groups of hex, often shortened with :: (for example 2001:db8::1). Link-local addresses start with fe80: and never appear here — only the public peer that reached this host.
